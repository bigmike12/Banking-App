# Banking App

### React Banking Interface

A frontend banking application built with React, focused on financial account interfaces, reusable UI components and responsive product experiences.

## Highlights

- Banking dashboard experience
- Account and transaction-oriented UI
- Reusable React components
- Responsive layouts
- Client-side application state and interactions

## Tech Stack

- React
- JavaScript
- CSS
- Create React App

## Run Locally

```bash
yarn install
yarn start
```

The application runs at `http://localhost:3000`.
